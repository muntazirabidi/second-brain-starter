---
name: weekly
description: Weekly review of the second brain. Summarise the week, point out connections, ask three quiz questions, list gaps, then save a version with git. Use when the user says weekly, weekly review, wrap up the week, or end of week.
---

1. From `wiki/log.md`, list what was captured and ingested in the last seven days.
2. Point out two or three connections between new and older pages the user may not have noticed.
3. Ask three quiz questions, one at a time, on this week's pages. Mark each answer against the wiki and link the page. If they miss one, add a line under "Sticking points" on that topic page.
4. List gaps: topics mentioned often without a page, and **Disagreement** marks still open.
5. Add a `weekly` entry to `wiki/log.md`.
6. Show `git status`, then ask before running `git add -A` and `git commit -m "Weekly review YYYY-MM-DD"`. If git is not set up, offer to set it up.
